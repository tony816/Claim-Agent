소스 파일

    발명 자료·도면은 원자료로, 선행기술은 비교 자료로, 정식 명세서는 최종 검증 근거로 전달됩니다. 파일을 이 화면에 끌어 놓아도 됩니다.

        에이전트 모델 설정
        구독 계정을 연결하고, 역할에 맞는 모델을 선택하세요.
        
  
        
  
        1. 계정 연결
        
    
        
    
        공식 CLI가 브라우저 로그인과 OAuth 갱신을 처리합니다. 이 앱 전용 로그인이 필요하며, 인증 정보는 이 컴퓨터의 CLI 저장소에 보관됩니다. 구독 사용량 한도와 계정별 추가 사용 정책이 적용됩니다.
        
  
        
  
        
    
        2. 기본 모델
        일반 대화·요청 분류와 ‘기본 설정 따름’ 역할에 적용됩니다.
        
      
        
    
        
    
        3. 서브에이전트별 모델
        
      
        제공자와 모델을 서로 다르게 지정할 수 있습니다. 추론 강도는 해당 모델이 지원해야 합니다. 모델 ID를 직접 입력할 수도 있습니다.
