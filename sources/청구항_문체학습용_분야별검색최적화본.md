# 청구항 문체 학습용 분야별 검색 최적화본 — 역사 코퍼스

> **용도:** 한국어 특허 청구항의 문형을 국소 검색하고, `07_용어표현_출처게이트.md`에 따라 이미 확정된 기술 개념의 표면 명칭·띄어쓰기·형상 술어를 정확 검색하기 위한 역사 코퍼스이다. 기본 컨텍스트나 긍정 정답 집합으로 사용하지 않는다.
>
> **원문 상태:** 청구항 문언은 외부 원본 `청구항_문체학습용_엄격선별본.md`에서 그대로 옮겼으며, 이번 단계에서는 청구항을 수정하지 않았다. 원문 무수정은 출처 충실성을 뜻할 뿐 정확성·명확성·권리범위 적정성 검증을 뜻하지 않는다.
>
> **메타데이터 상태:** 기술분야, 카테고리, 구조 패턴, 밀도 및 종속항 전개 태그는 출처 이력 보존용 편집 메타데이터일 뿐이며 검색·선택·품질 판단에 사용하지 않는다. 검색은 이미 특정된 국소 통사 문제의 정확한 관계·문형에만 한정한다.
>
> **검증 상태:** 전 예시는 기존 코퍼스 수록 기준만 통과했으며 최신 `독립항_작성_성공조건.md`는 미검증이다. 아래 상태 라벨은 법적·기술적 품질을 보증하지 않는다.
>
> **활성 시점:** 현재 발명의 주골격, 구성 계층, 핵심 협동관계, 최소충분 한정 집합 및 보조 예시 없는 의미 초안이 확정된 뒤, 국소 통사 문제가 남거나 용어·표현 출처 게이트에서 확정 개념의 표면 표현을 정확 검색할 때만 사용한다.
>
> **사용 제한:** 예시의 기술적 구성·수치·재질·효과를 현재 발명에 전용하지 않는다. 전체 독립항의 아키텍처, 구성 개수, 배열, 밀도 또는 종속항 이동 방식을 모방하지 않는다. 이 파일은 별도 `claim-style-adjuster`가 PRE_STYLE 의미 초안 뒤에만 사용한다. 국소 통사 문제에는 정확한 문장 조각만 최대 1~2개 읽고, 해당 조각이 조건 2·3·9를 통과하며 한정 배치에 관여하면 조건 8도 통과한 경우에만 사용한다. 용어·표현 출처 검색에는 이미 확정된 각 개념의 정확한 후보 표현과 필요한 최소 문맥만 읽고, 기술내용은 채택하지 않는다. 적용 후 현재 후보의 조건 4·3·9, CLAIM_STYLE_GATE, TERM_EXPRESSION_GATE와 범위 불변시험을 다시 수행하고, 범위 영향이 있으면 style 결과를 확정하지 않은 채 조건 1·4·8 및 필요한 상위 역할로 돌아간다. 어느 재검사라도 통과하지 못하거나 주골격·계층·한정 집합·명제 트리·권리범위가 바뀌면 조각을 폐기하고 보조 예시 없는 의미 초안으로 되돌린다. 적합한 조각이 없으면 `예시 없음` 또는 `NEW_NEUTRAL_TERM`으로 종료한다.
- 수록 예시: **20세트**
- 수록 청구항: **143개**
- 기술분야 그룹: **7개**
- 원문 출처: `명세서 병합본.docx`의 청구범위

## 보존 메타데이터 필드 — 라우팅·선택 금지

아래 필드는 코퍼스의 출처 이력과 기존 편집 상태를 설명할 뿐이다. 기술분야·카테고리·아키텍처·밀도·종속항 구조·키워드로 예시를 찾거나 선택하지 않는다. 국소 문제 검색에는 `관계·동작 태그`와 실제 청구항 구절 중 이미 특정된 통사 문제에 직접 대응하는 문형만 사용할 수 있다.

- **기술분야(대/세):** 발명의 적용 영역과 세부 기술 대상
- **청구항 카테고리:** 장치, 시스템, 방법, 물품 또는 복수 독립항 여부
- **독립항 아키텍처:** 독립항에서 결합되는 구성군의 구조
- **독립항 밀도:** 구성·관계의 문장 밀도를 낮음·중간·높음으로 구분
- **종속항 구조:** 방사형, 연쇄형, 혼합형 또는 복수 독립항형
- **종속항 전개:** 종속항이 구체화되는 순서
- **관계·동작 태그:** 위치, 결합, 이동, 제어 등 청구항 문언 검색어
- **검색 키워드:** 기존 편집 메타데이터로만 보존하며 검색축으로 사용하지 않음
- **문체 관찰 포인트:** 해당 예시에서 관찰되는 문형 또는 전개 형태. 권장·적합성 판정을 의미하지 않음

## EX-01 · 비산 방지 정수기 {Anti-Scattering Water Purifier}

- 원문 식별: `003` / `APM-2025-0217`
- 기술분야(대): 생활가전·위생
- 기술분야(세): 정수·출수 제어; 용기 감지; 가변 노즐
- 청구항 카테고리: 장치
- 독립항 아키텍처: 본체 + 측정부 + 신축부 + 구동부 + 제어부의 센서·구동·제어 결합형
- 독립항 밀도: 중간
- 종속항 구조: 혼합형 — 제어 산출식의 3단 연쇄와 센서 종류·배치의 병렬 분기
- 종속항 전개: 거리·수위 산출 → 길이 제어 → 센서 종류 → 센서 배치
- 관계·동작 태그: 안착; 출수; 연통; 측정; 신축; 구동; 제어; 산출; 연장
- 검색 키워드: 정수기; 용기; 출수부; 텔레스코픽; 높이 측정; 직경 측정; 적외선 센서; 초음파 센서; 액추에이터
- 문체 관찰 포인트: 센서의 측정값과 입력신호를 이용해 가변 구조를 제어하는 장치 청구항과 계산식 기반 종속항.
- 정규화 태그: `TF_생활위생 | SUB_정수출수 | CAT_장치 | ARCH_센서구동제어 | REL_연통_신축_측정 | DEP_혼합연쇄 | DENS_중간`
- 상태: 기존 코퍼스 수록 · 청구항 원문 무수정 · 최신 독립항 성공조건 미검증

### 【청구범위】

#### 【청구항 1】

용기가 안착되는 안착부와, 물을 출수하는 출수부가 구비되고, 물의 출수량에 관한 입력신호가 입력되는 정수기 본체;
상기 용기의 크기를 측정하는 복수의 측정부;
상기 출수부와 연통되는 복수의 관이 텔레스코픽 구조로 형성되는 비산 방지부;
상기 비산 방지부의 신축 길이를 조절하는 구동력을 제공하는 구동부; 및
상기 용기의 크기와 상기 입력신호에 따라 상기 구동부의 동작을 제어하는 제어부;
를 포함하는 비산 방지 정수기.

#### 【청구항 2】

제1항에 있어서,
상기 제어부는 상기 안착부와 상기 비산 방지부 사이의 최장 거리값이 기 입력되고, 상기 최장 거리에서 상기 용기의 높이를 감산한 제1거리값을 산출하고, 상기 제1거리값을 초과하여 상기 비산 방지부를 더 연장하도록 상기 구동부를 동작시키는 비산 방지 정수기.

#### 【청구항 3】

제2항에 있어서,
상기 제어부는 상기 출수량을 상기 용기의 단면적으로 나눈 수위 값을 상기 최장 거리에서 감산한 제2거리값을 산출하고, 상기 제2거리값 미만으로 상기 비산 방지부를 더 연장하는 비산 방지 정수기.

#### 【청구항 4】

제3항에 있어서,
상기 제어부는 상기 제1거리값과 상기 제2거리값이 상이하면 상기 제1거리값과 상기 제2거리값의 평균값만큼 상기 비산 방지부를 연장하는 비산 방지 정수기.

#### 【청구항 5】

제1항에 있어서,
상기 복수의 측정부는 적외선 센서 또는 초음파 센서를 포함하는 비산 방지 정수기.

#### 【청구항 6】

제1항에 있어서,
상기 복수의 측정부 중 일부는 상기 정수기 본체에 구비되어 상기 용기의 높이를 측정하고, 또 다른 일부는 상기 안착부에 구비되어 상기 용기의 직경을 측정하는 비산 방지 정수기.

## EX-07 · 펌핑 용기 거치대{Pumping Container Holder}

- 원문 식별: `035` / `APM-2022-0584`
- 기술분야(대): 생활위생·디스펜서
- 기술분야(세): 펌핑 용기; 잔량 측정; 데이터 처리; 알람
- 청구항 카테고리: 장치
- 독립항 아키텍처: 설치 몸체 + 가압부 + 복수 측정부 + 데이터 처리부의 센서·정보처리형
- 독립항 밀도: 중간
- 종속항 구조: 혼합형 — 잔량 알람의 3단 연쇄와 설치·재질·감지 구조의 병렬 분기
- 종속항 전개: 표시·알람 → 임계값 제어 → 사용자 단말 → 탄성 설치부 → 승강 삽입부 → 동력전달·인체감지
- 관계·동작 태그: 설치; 가압; 측정; 수신; 도출; 표시; 알람; 팽창; 삽입결합; 승강
- 검색 키워드: 디스펜서; 펌핑 용기; 잔량 센서; 무게 센서; 수위 센서; 데이터 처리; 알람; 인체 감지
- 문체 관찰 포인트: 복수 센서 정보를 결합해 상태값을 도출하고 표시·알람하는 장치 청구항.
- 정규화 태그: `TF_생활위생 | SUB_잔량모니터링 | CAT_장치 | ARCH_센서정보처리 | REL_측정_도출_알람 | DEP_혼합연쇄 | DENS_중간`
- 상태: 기존 코퍼스 수록 · 청구항 원문 무수정 · 최신 독립항 성공조건 미검증

### 【청구범위】

#### 【청구항 1】

바닥 또는 벽면에 설치되고, 세정액을 수용하는 펌핑 용기가 설치되는 용기 설치부가 구비되는 몸체;
상기 몸체에 구비되고, 상기 펌핑 용기를 가압하며 세정액을 토출시키는 가압부;
상기 펌핑 용기가 상기 가압부에 의해서 가압된 횟수를 측정하는 펌핑 측정부;
상기 용기 설치부 또는 상기 펌핑 용기의 내부에 구비되어서, 상기 펌핑 용기의 무게 또는 세정액의 수위를 측정하는 잔량 측정부; 및
상기 펌핑 측정부와 상기 잔량 측정부가 측정한 측정 정보를 수신하고, 상기 측정 정보를 기초로 세정액의 잔량 정보를 도출하고, 상기 세정액의 잔량 정보를 시각적 또는 청각적으로 표시하는 데이터 처리부;
를 포함하는 펌핑 용기 거치대.

#### 【청구항 2】

제1항에 있어서,
상기 데이터 처리부는 세정액의 잔량을 시각적으로 표시하는 표시부와, 세정액 잔량에 대한 시각적 또는 청각적 알람을 송출하는 알람부가 구비되는 펌핑 용기 거치대.

#### 【청구항 3】

제2항에 있어서,
상기 데이터 처리부는 세정액의 잔량이 소정 값 이하인 경우 상기 알람부가 세정액 보충을 권고하는 알람을 송출하도록 제어하는 펌핑 용기 거치대.

#### 【청구항 4】

제3항에 있어서,
상기 알람부는 상기 표시부 또는 사용자의 디바이스에 시각적 알람을 송출 가능한 펌핑 용기 거치대.

#### 【청구항 5】

제1항에 있어서,
상기 용기 설치부는 탄성소재로 형성되어서, 상기 펌핑 용기가 설치되면 상기 펌핑 용기의 크기에 대응되는 크기로 팽창하는 펌핑 용기 거치대.

#### 【청구항 6】

제1항에 있어서,
상기 몸체는 상기 용기 설치부가 삽입 결합되는 홈 형태의 삽입부가 형성되고,
상기 삽입부는, 상기 삽입된 용기 설치부의 승강 이동이 가능하도록, 상기 몸체의 길이 방향을 따라 연장되는 펌핑 용기 거치대.

#### 【청구항 7】

제1항에 있어서,
상기 몸체는 바닥에 설치되는 경우 상기 가압부가 상기 펌핑 용기를 가압하도록 동력을 전달하는 동력전달부가 상기 몸체의 하부에 설치되는 펌핑 용기 거치대.

# 분야 7. 에너지·화재안전

## EX-12 · 배터리팩 화재 소화 시스템{Battery-Pack Fire Extinguishing System}

- 원문 식별: `071` / `APM-2023-0731`
- 기술분야(대): 배터리 안전·소방
- 기술분야(세): 배터리팩 화재; 온도 감지; 신축 관로; 원격 제어
- 청구항 카테고리: 시스템
- 독립항 아키텍처: 신축 연관부 + 온도 측정부 + 제어부 + 외부 소화용 수전의 감지·공급형
- 독립항 밀도: 중간
- 종속항 구조: 방사형 — 관로 분기, 센서 위치, 원격통신, 개폐부를 각각 직접 한정
- 종속항 전개: 분기관 → 온도 센서 위치 → 원격 제어 → 외부 노출 개폐부
- 관계·동작 태그: 내외부 연통; 신장; 온도 측정; 제어; 연결; 공급; 분할; 원격 통신; 개폐
- 검색 키워드: 배터리팩; 화재 소화; 소화수; 신축관; 온도 센서; 원격 관제; 개폐부; 소화물질
- 문체 관찰 포인트: 위험 감지에 따라 신축 유로를 제어하고 외부 소화원을 내부로 연결하는 안전 시스템.
- 정규화 태그: `TF_에너지안전 | SUB_배터리소화 | CAT_시스템 | ARCH_감지신축유로 | REL_연통_신장_공급 | DEP_방사형 | DENS_중간`
- 상태: 기존 코퍼스 수록 · 청구항 원문 무수정 · 최신 독립항 성공조건 미검증

### 【청구범위】

#### 【청구항 1】

제품에 내장된 배터리팩의 내부와 상기 제품의 외부를 연통시키는 관 형상을 갖고, 상기 제품의 외부를 향한 단부가 신장 가능하게 형성되는 연관부;
상기 배터리팩의 내부 온도를 측정하는 복수의 온도 측정부;
상기 온도 측정부의 측정 온도에 따라 상기 연관부의 길이 신장을 제어하는 제어부; 및
상기 제품의 외부에 구비되고, 상기 연관부와 연결되어서 상기 배터리팩의 내부로 물 또는 소화물질을 공급하는 소화용 수전;
을 포함하는 배터리팩 화재 소화 시스템.

#### 【청구항 2】

제1항에 있어서,
상기 연관부는 상기 배터리팩을 향한 부분이 복수의 관으로 분할 형성되어서 상기 배터리팩의 내부와 연통되는 배터리팩 화재 소화 시스템.

#### 【청구항 3】

제1항에 있어서,
상기 복수의 온도 측정부 중 일부는 상기 배터리팩의 내표면 온도를 측정하도록 구비되는 배터리팩 화재 소화 시스템.

#### 【청구항 4】

제1항에 있어서,
상기 제어부는 스마트폰 또는 PC의 관제 서버와 원격 통신하도록 형성되어서 통신 명령에 따라 상기 연관부의 길이 신장을 제어하는 배터리팩 화재 소화 시스템.

#### 【청구항 5】

제1항에 있어서,
상기 제품의 하우징에서 상기 연관부가 외부로 노출되는 부분에 구비되고, 상기 연관부의 길이가 변경될 때 개폐되는 개폐부를 더 포함하는 배터리팩 화재 소화 시스템.
