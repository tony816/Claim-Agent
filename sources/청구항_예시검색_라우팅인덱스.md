# 청구항 예시 검색 라우팅 인덱스

> 이 파일은 실제 청구항 문언을 수록하지 않는 국소 통사 검색용 목차다. 기본값은 `예시 미사용`이다. `claim-drafter`는 이 파일을 읽지 않고, 별도 `claim-style-adjuster`만 PRE_STYLE 의미 초안 뒤 제한적으로 사용할 수 있다. 기술분야, 청구항 카테고리, 구성 개수 또는 전체 아키텍처의 유사성은 검색·선택 근거로 사용하지 않는다. 이미 확정된 기술 개념의 표면 명칭·띄어쓰기·형상 술어를 정확 검색하는 별도 절차는 `07_용어표현_출처게이트.md`를 따르며, 이 인덱스의 전체 청구항 모방 금지를 완화하지 않는다.

## 0. 검색 전 하드 게이트

다음 조건을 모두 충족하지 않으면 코퍼스를 열지 않고 `예시 없음`으로 종료한다.

1. 현재 발명의 0단계 주골격 3~5개, 구성 계층, 핵심 협동관계 및 최소충분 한정 집합이 확정되어 있다.
2. 보조 예시 없이 `revision_status: PRE_STYLE — NOT_GATE_ELIGIBLE` 의미 초안과 단일 명제 트리가 먼저 작성되어 있다.
3. 해결되지 않은 문제가 아래 표의 국소 문제처럼 정확한 구절과 관계 단위로 특정되어 있다.
4. 후보의 전체 독립항이 아니라 해당 문제를 다루는 정확한 문장 조각만 읽는다.
5. 선택한 조각이 현재 용도에서 조건 2·3·9를 통과하고, 한정 배치와 범위에 관여하면 조건 8도 통과한다.

예시 조각은 최대 1~2개만 사용한다. 적용 후 CLAIM_STYLE_GATE, 조건 4·3·9와 범위 불변시험을 다시 수행한다. 범위에 영향이 있으면 style 결과를 확정하지 않은 채 조건 1·4·8과 필요한 상위 역할로 돌아가고, 주골격·구성 계층·한정 집합·명제 트리 또는 권리범위가 달라졌으면 예시 적용을 폐기한다.

## 1. 국소 문제별 검색 축

| 국소 문제 | 검색할 문형·관계 | 사용 금지 |
|---|---|---|
| 머리명사 결속 | 관형절의 끝과 상위 머리명사가 하나로 닫히는 조각 | 유사 분야의 전체 독립항 |
| 하위 구성 귀속 | 하위 구성의 관계를 닫고 상위 구성에 결속하는 조각 | 후보의 전체 구성 계층 |
| 복수 집합 분배 | 분배 원천·대상·대응 방식이 명시된 조각 | `각각`이라는 단어만 보고 선택 |
| 공간 형성·수용 | 구조가 공간을 형성하고 대상이 그 공간에 수용되는 관계 조각 | 유사 장치의 부품·형상 차용 |
| 판·면·단부 귀속 | 상위 구성과 일면·단부의 귀속을 닫는 조각 | 전체 아키텍처·구성 개수 모방 |
| 구성 간 작동 | 주체·입력·대상·작용이 닫힌 관계 조각 | 센서·제어 구성을 새로 도입 |
| 방법 단계 | 단계 주체·입력·산출물·다음 단계 인계가 닫힌 조각 | 후보 방법의 전체 공정 순서 모방 |
| 데이터·제어 귀속 | 입력·처리·판단·출력 또는 제어 대상이 닫힌 조각 | 유사 시스템의 처리 로직 차용 |
| 조성·범위 귀속 | 성분, 수치범위, 결합·반응 대상의 문언상 귀속이 닫힌 조각 | 유사 조성의 성분·수치 차용 |

기술분야나 완성 청구항의 구조상 근접성을 검색축으로 쓰지 않는다. 코퍼스에 남아 있는 분야·아키텍처 태그는 역사적 편집 메타데이터일 뿐이며 이 인덱스의 라우팅 규칙이 아니다.

## 2. 검색 절차

1. 현재 후보의 문제 구절과 해결해야 할 관계를 한 문장으로 기록한다.
2. 위 표의 국소 문제와 문형으로만 코퍼스를 검색한다.
3. 후보 조각이 있는 정확한 청구항과 구절만 읽고, 그 앞뒤도 선행기재 확인에 필요한 최소 범위로 제한한다.
4. 현재 용도에서 조건 2·3·9와 필요한 경우 조건 8을 독립적으로 판정한다.
5. 통과한 조각을 최대 1~2개만 적용한다. 통과한 조각이 없으면 `예시 없음`으로 끝낸다.
6. 적용 후 CLAIM_STYLE_GATE, 조건 4·3·9와 범위 불변시험을 다시 수행한다. 범위 영향이 있으면 style 결과를 확정하지 않고 조건 1·4·8과 필요한 상위 역할로 돌아간다.
7. 어느 재검사라도 통과하지 못하면 조각을 폐기하고 보조 예시 없는 의미 초안으로 되돌린다.

## 3. 사용 기록

다음 항목을 모두 남기지 못하면 예시 조각을 사용하지 않는다.

`해결 대상 / 검색한 국소 문제·문형 / 예시 ID·청구항·정확한 조각 / 조건 2·3·9(필요시 8) 판정 / 범위 불변 결과`

`예시 없음`은 정상적이고 완결된 검색 결과다.
