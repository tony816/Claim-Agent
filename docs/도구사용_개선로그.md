# 도구 사용 개선 로그

Claude Code가 이 세션에서 청구항을 직접 지휘하면서 Claim-Agent의 일부 도구만 골라 쓸 때, 쓰다가 발견한 결함·불편을 적는다.
한 항목은 한 문제다. 고친 항목은 `상태`를 `FIXED (커밋)`로 바꾼다.

## 지휘 방식

- 지휘: Claude Code가 CLAUDE.md 절차대로 `.claude/agents/`의 역할 에이전트(설계·작성·스타일·성공조건·syntax·OA·blind·picture)를 호출한다. Python 파이프라인(`claim-agent run`)은 쓰지 않는다.
- 골라 쓰는 도구 (필요할 때만)

| 도구 | 쓰는 곳 | 비고 |
|---|---|---|
| `pipeline/claimtext.py` | 청구항 세트 파싱, 부모항 체인, 평문화, exact sha256 | revision 봉인·blind 입력 구성 |
| `pipeline/blind_guard.py` | blind 입력에 설계·원자료가 섞였는지 검사 | blind 호출 직전 |
| `graph invention` / `graph ideas` | 원자료가 길 때 아이디어 시트 | Gemini 1회 |
| `prior_art/wips.py` 대신 WIPS 커넥터 | 선행기술 검색 (요청 시) | `.env`에 `WIPS_API_KEY` 없음 |
| Jev 커넥터 (`noul`) | 검색 후보 선별 | OpenRouter 경유 코드 대신 |
