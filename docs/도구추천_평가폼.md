# 자유 작업 도구 추천 · 평가 폼

자유 작업 대화의 답마다 붙는 두 가지다. 둘 다 사용자 참고·앱 개선용 측정이며 게이트·근거·원자료가 아니다(CLAUDE.md `자유 작업 모드` · 도구 추천·평가 폼).

## 흐름

1. 일반 에이전트의 답(`FREE`)이나 선택 검수 결과(`REVIEW`)가 `complete`로 끝나면 `web.py`의 `execute`가 `advise`를 부른다.
2. `advise`는 `.tui/requests/advice-<id>/advice-request.json`을 쓰고 `python -m claim_agent.tool_advice`를 띄운다(대화의 모델 설정을 그대로 고정해 넘긴다). 입력창은 막지 않는다.
3. 자식은 `roles.tool-recommender` 모델로 한 번 호출해 `advice.json`을 쓴다. 호출이 실패하거나 300초 안에 끝나지 않으면 웹이 같은 요청으로 `rules`(코드가 센 신호)를 붙인다.
4. 결과는 그 답 메시지의 `advice`에 붙고 화면의 `도구 추천` 카드가 된다. 추천 도구를 누르면 작업 도구 패널에서 그 도구·대상 청구항을 고르고, 멘트를 누르면 입력창에 넣는다. 실행은 Enter다.
5. 그 뒤 사용자가 실행한 검수·판례 도구와 보낸 글에 남은 멘트는 그 답의 `used_tools`에 쌓인다(추천 카드에서 골랐으면 `via: advice`, 아니면 `panel`).
6. 평가 폼을 저장하면 메시지의 `evaluation`이 바뀌고 `.tui/web/evaluations.jsonl`에 한 줄이 더해진다.

추천 입력: 답 전문(앞 24,000자), 그 답이 응한 사용자 요청, 대상 청구항 블록(검수 결과면 그 검수가 읽은 문언), 대화에서 이미 실행한 도구, 원자료 수(도면·이미지 수), 저장된 피드백 멘트. 원자료 본문·대화 기록은 보내지 않는다.

## 기록 형식 (`evaluations.jsonl`, 한 줄 = 한 번 저장)

| 필드 | 뜻 |
|---|---|
| `ts`, `session`, `project`, `message` | 저장 시각, 대화·프로젝트·답 id |
| `mode`, `kind` | `FREE`·`REVIEW`, 그리고 `REVISED`(검수 뒤 고친 문언) 구분 |
| `revision` | 같은 답을 몇 번째로 저장했는지. 집계는 답마다 마지막 줄만 쓴다 |
| `provider`, `model` | 그 대화의 연결 방식·기본 모델(일반 에이전트가 쓴 모델) |
| `advice` | `source`(`agent`·`rules`·없으면 `null`), `model`, 추천 `tools`(id 목록), `phrases`, 코드가 센 `signals` |
| `used` | 자동 기록된 사용 도구 `{tool, via, phrase_id}` |
| `evaluation` | `score`(1~5), `usable`(`as_is`·`edit`·`unusable`), `fit`(`hit`·`partial`·`miss`), `tags`, `tools`(`{tool, rating: good·ok·bad, note}`), `feedback` |

도구 id: `claim-style-adjuster`, `syntax-scope-reviewer`, `oa-strategy-reviewer`, `claim-success-reviewer`, `blind-claim-reconstruction-reviewer`, `enforce`, `find`, `features`, `phrase`(피드백 멘트).
문제 유형: `scope_narrow`, `scope_broad`, `missing`, `unsupported`, `unclear`, `functional`, `format`, `verbose`.

## 평가 측정 탭의 지표

- 평가한 답 / 추천을 받은 답(커버리지)
- 청구항 평균 점수와 분포, 사용 가능성 비율
- 추천 적합(맞음·일부·아님)
- 추천 사용률 = 추천한 도구 중 사용자가 평가 폼의 사용한 도구로 남긴 비율
- 추천 포착률 = 사용한 도구 중 추천에 있던 비율
- 도구별 추천·사용 횟수와 도움 됨 비율(도움 됨 1, 보통 0.5, 안 됨 0의 평균)
- 문제 유형 빈도, 대화 모델별 평균 점수, 추천 출처(에이전트·규칙)별 적합
- 최근 피드백 20건

원본은 탭의 `원본 JSONL 내려받기`(`/api/evaluations/export`)로 받는다.

## 끄기

`claim-agent.yaml`의 `conversation.tool_advice: "off"`면 추천 호출을 하지 않는다. 평가 폼은 그대로 남는다.
