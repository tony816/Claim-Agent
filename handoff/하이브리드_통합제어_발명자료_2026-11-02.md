## 2. 발명 요약 (슬라이드 7 원문)

제목 줄: 「Single/Batch Unit(98/48/24well) 프로토콜, 통합 제어」 `[불일치 Q5: 다른 슬라이드는 96/48/24 well]`

특징(노란 강조): 「단일 UI에서 single/batch unit 관리, 자동 배정/재배치 스케줄링 엔진, 슬롯/unit 단위 동적 스케줄링」

**[한 줄 요약]** 「하나의 공통 콘솔에 Single Unit과 Batch Unit을 혼합하여 최대 3대까지 연결하고, 전원 변환·분배와 통신은 콘솔이 공통 제공하되 실시간 모션·온도 제어는 각 PCR 유닛에 분산 배치함으로써 배선을 간소화하고 이종 장비의 통합 운용 및 확장을 가능하게 한 PCR 플랫폼」

**[발명의 목적]** 「장비별로 제어 보드 및 전원부가 중복 구비됨에 따른 비용·공간·서비스성 저하, 그리고 콘솔이 각 유닛의 모터·펠티어까지 직접 제어함에 따른 배선 복잡화(200핀 케이블 2종 또는 다수의 개별 케이블) 문제를 해결하고, 서로 다른 처리 용량과 형태를 갖는 PCR 유닛을 단일 인터페이스로 통합 운용할 수 있는 확장형 시스템을 제공함」

**[특허 포인트]**

1. 「(하드웨어 측면) Batch+single 통합 제어 플랫폼을 구현할 수 있는 콘솔」
   - 「(batch, single, 콘솔(통신) 포함 독립항. 전원은 종속항)」
   - 발명자 메모 문장(초록 강조는 앞부분): 「복수의 서로 다른 유형의 PCR 유닛과 연결되는 콘솔을 포함하는 PCR 시스템으로서, 각각의 PCR 유닛은 온도 제어부, 모션 제어부를 포함하고, 콘솔은 전원부와 통신부를 포함하며, 콘솔과 각각의 PCR 유닛은 전원 케이블 및 통신 케이블을 통해 연결되는 것을 특징으로 함 (독립적인 열온도 제어 가능, 메인 컨트롤러로 통합 제어 가능한 구성은 공지기술)」
   - `[판독 주의 Q10]` 「열온도」는 원문 표기 그대로다. 슬라이드 1의 선행기술 메모는 「독립적인 열블록 온도제어」로 적었다.
   - 이 문장은 발명자의 방향 메모다. 프로젝트 USER_LOCK에 넣지 않는 한 확정 문언이 아니다.
   - 같은 문장 안에서 발명자가 「공지기술」로 표시한 것: 독립적인 열(블록) 온도 제어, 메인 컨트롤러에 의한 통합 제어.
2. 「(소프트웨어 측면) PCR 유닛의 종류와 상태를 인식하는 컴퓨터로 단일 UI에서 Batch/single 유닛 통합 관리」
   - 「유닛 또는 슬롯 단위로 자동 배정, 재배치하는 동적 스케줄링 알고리즘, 동일 assay에 대해 well 수, 블록 구조, 광학 구조 차이를 고려한 프로토콜 매핑/변환 로직, 일부 슬롯/유닛의 장애 또는 점검 모드 발생시 다시 스케줄링하는 알고리즘 등 포함」
   - 「*확정되면 종속항 또는 별도 출원 고려」
   - 알고리즘의 입력·판단 규칙·순서는 슬라이드에 없다(Q9).

## 3. 시스템 구성 (슬라이드 1·2·3)

### 3-1. 통합 소프트웨어 측면 (슬라이드 1 왼쪽, 슬라이드 2)

- 슬라이드 2 머리 문장: 「6개의 strip형 샘플뿐만 아니라, 96-well plate와 같은 샘플도 검출할 수 있도록 구성된 통합 제어 하이브리드 시스템을 제공함」 `[불일치 Q4: Single Unit은 4-slot으로 적혀 있음]`
- 「특허: Single Unit(4-slot)과 Batch Unit(96/48/24 well)을 하나의 소프트웨어/플랫폼에서 통합 운전하는 시스템」
  - 「Single/Batch Unit의 상태를 단일 UI에서 관리」
  - 「통합 SW의 UI에서 장비를 각각 제어 할 수 있는 방식」
  - 「동일 Assay를 Single ↔ Batch 간에 수행할 때 UI 일관성을 확보」
- 연결도(블록 5종, 선으로 연결):

```
통합 Viewer / Controller ── 매핑 엔진 ─┬─ Console ─┬─ Single #1
                                       │           └─ Single #2
                                       └─ Console ─── Batch Unit
```

  - 이 그림에는 콘솔이 2개(Single용 1, Batch용 1)로 그려져 있다 `[불일치 Q1]`.
  - 「매핑 엔진」의 동작은 그림에 이름만 있고 설명이 없다(Q9).

### 3-2. 콘솔 외장화 측면 (슬라이드 1 오른쪽, 슬라이드 3)

- 「특허: 제어/전원 Console을 외장화하여 Single/Batch Unit을 통합 제어」
  - 「외부 Console + 복수의 PCR Unit(Single, Batch)로 구성된 플랫폼」
  - 「서로 다른 용량/형태의 Unit이 동일 인터페이스와 프로토콜을 사용」
  - 「Console과 Unit을 독립 교체·업그레이드 가능한 분리형 구조」
- 3D 개념도(슬라이드 1·3 공통)
  - 상단 노란 표시: 「※ 업데이트 내용: 제어/전원 공급 Console Single과 Batch를 분리」 `[불일치 Q1]`
  - 「제어/전원 공급 Console」 상자 2개가 나란히 있다.
  - 왼쪽 콘솔 아래: 「Single 검사 Unit #1」, 「Single 검사 Unit #2」가 옆으로 붙어 있고, 각 유닛 앞면에 세로 칸 「1 2 3 4」가 있다. 아래 주황 화살표 「확장 가능」(오른쪽 방향).
  - 오른쪽 콘솔 아래: 「Batch 검사 Unit」, 옆에 「※ 별도의 장비 형태」. 아래 파란 글씨 「※ 96 well 먼저 개발 후 24 well, 48 well 까지 확장」.
  - 연결선: 왼쪽 콘솔에서 Single Unit #1·#2로 각각 검은 선과 빨간 선이 내려가고, 오른쪽 콘솔에서 Batch Unit으로 검은 선 하나가 내려간다. 선 색의 의미는 적혀 있지 않다(Q11).
- 오른쪽 블록도: 「Console ─ Single #1, Single #2」, 별도로 「Console ─ Batch」.

## 4. 하드웨어 상세 (슬라이드 4·5·6)

### 4-1. 통합 제어 콘솔 — 배선 간소화 (슬라이드 4)

- 머리 문장: 「qPCR Unit과 Console간 케이블 배선 구조 간소화 구조: * 중계 보드 통한 전원/통신 케이블 2종 구성 (※ 중계 보드가 없다면 케이블 18종)」 `[불일치 Q6: 슬라이드 7의 '200핀 케이블 2종'과 관계 미상]`
- 3D 투시도 2개와 그 사이 양방향 화살표 2개(「전원 케이블」, 「통신 케이블」).
  - 「Single qPCR」 투시도 라벨: 광학 제어 보드(위쪽 판), 광학 모듈, Heat Lid(윗면 판), *중계 보드 (전원/통신)(앞쪽 남색 판), 온도 모듈 보드(옆면 적색 판).
  - 「Console」 투시도 라벨: 모션 제어 보드(세로 판), 메인 제어 보드(가로 판), 온도 제어 보드(가로 판), *중계 보드 (전원/통신)(아래 남색), 모터 드라이버(옆면에 여러 개 세워 꽂힘), SMPS(앞쪽 아래, 팬 2개 보임).

Single qPCR 쪽 표:

| 분류 | 보드 명 | 기능 |
|---|---|---|
| 광학 모듈 | 광학 제어 보드 | 각 보드들에 대해 통신 및 통합 제어 |
| 광학 모듈 | LED 보드 | LED 소자를 통해 발광 |

| 중계 보드 | 전원/통신 중계 보드 | Console로 부터 모터 제어 신호 및 전원 중계 |

### 4-2. Single qPCR 회로 보드 계층 구조 (슬라이드 5, 슬라이드 6은 같은 그림의 색 강조본)

머리 문장: 「Single qPCR 회로 보드 계층 구조 상세: 중계 보드의 역할」

**[Single – qPCR] 상자 안 블록**

- 광학 제어/스캔 보드
- 광학 모듈 — 「회로 보드 3종 (LED, PD, Feedback)」
- Y축 모터, X축 모터 (각 1개)
- Heat Lid (가로 막대)
- Z축 모터 + Drawer 모터 쌍 4개
- 온도 모듈 4개 — 각각 「Peltier / 온도 센서 / FAN」
- 통합중계 보드 — 기능 목록:
  - 「광학 모듈 전원 공급」
  - 「X-Y축 모터 Ethernet 통신 중계」 (Q8)
  - 「Z축, Drawer 모터 신호 전달」
  - 「Heat Lid 제어」
  - 「온도 모듈 전원 / 제어 신호 중계」
- 온도 모듈 중계 보드 — 기능 목록:
  - 「온도 모듈 전원 공급」
  - 「Pelter 제어 신호 전달」 (원문 표기 「Pelter」)
  - 「온도 센서 값 입력 후 ADC 변환」
  - 「FAN 전원 공급」
- `[해석]` Z축·Drawer 모터 쌍 4개와 온도 모듈 4개는 Single Unit의 슬롯 4개(3-2절 「1 2 3 4」)에 하나씩 대응하는 것으로 보인다. 슬라이드에 대응 관계가 글로 적혀 있지는 않다.

**[Console] 상자 안 블록**

- SOM + 중계 보드 — 「디스플레이, Console FAN / Ethernet Switch / 광학 모듈 및 온도 모듈 제어 / 모션 제어 보드 제어」

## 6. 슬라이드끼리 맞지 않는 곳 · 발명자 확인 질문

- **Q1 콘솔 수.** 3D 개념도는 「Console Single과 Batch를 분리」(콘솔 2대)이고, 26.07.13 상자와 한 줄 요약은 「콘솔 1개에 single unit, batch unit 총 3개」, 「하나의 공통 콘솔에 … 혼합하여 최대 3대까지 연결」이다. 출원 기준은 공통 콘솔 1대인가? 「최대 3대」의 조합(예: Single 2 + Batch 1)이 정해져 있는가?
- **Q2 모션 제어 위치.** 슬라이드 4·5·6의 블록도에서는 모션 제어 보드·모터 드라이버가 Console에 있다. 그런데 26.07.13 상자는 「모션 제어 파트도 single unit 모듈에 배치」, 한 줄 요약은 「실시간 모션·온도 제어는 각 PCR 유닛에 분산 배치」, 특허 포인트 1은 「각각의 PCR 유닛은 온도 제어부, 모션 제어부를 포함」이다. 슬라이드 5·6의 블록도는 업데이트 전 구성(발명의 목적이 말하는 「콘솔이 각 유닛의 모터·펠티어까지 직접 제어」하는 구성)인가? 업데이트 후의 블록도가 있는가? 업데이트 후 Console에 남는 보드는 무엇인가(SMPS, SOM, 통합중계보드 등)?
- **Q3 온도 제어 위치.** 26.07.13 상자는 모션 제어만 유닛으로 옮긴다고 적었는데, 한 줄 요약은 모션·온도 둘 다 유닛에 분산한다고 적었다. 온도 제어 보드(NTC 기반 Peltier·FAN 구동)도 각 유닛으로 옮기는가?
- **Q4 Single Unit 수용 수.** 「Single Unit(4-slot)」과 그림의 칸 「1 2 3 4」에 비해 슬라이드 2는 「6개의 strip형 샘플」이다. 한 Single Unit의 슬롯 수와 슬롯 하나에 들어가는 시료 형태(strip, 튜브 수)는?
- **Q5 well 수.** 「98/48/24well」(슬라이드 1·7 제목)과 「96/48/24 well」(나머지)이 다르다. 98은 96의 오기인가?
- **Q6 케이블.** 슬라이드 4는 중계 보드로 「전원/통신 케이블 2종」(없으면 「18종」), 슬라이드 7은 문제점으로 「200핀 케이블 2종 또는 다수의 개별 케이블」을 든다. 200핀 케이블 2종이 슬라이드 4의 중계 보드 방식인가? 업데이트 후 콘솔–유닛 사이 케이블의 종류·심선 구성은?
- **Q7 히트리드.** 「탈부착 가능하고 개별 히트리드 사용」에서 「개별」은 슬롯마다 히트리드가 따로 있다는 뜻인가? 슬라이드 5의 「Heatlid도 개별로 제어될 수 있도록」과 같은 실시예인가? 이 출원에 히트리드 구성을 넣는가?
