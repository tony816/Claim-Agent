## DC-15 (주된 트리, TECHNICAL_SOLUTION_CANDIDATE)
- 근거: A 슬라이드 1 특허 포인트 1·2, female=제1·male=제2 라벨, 슬라이드 화살표 / B 3·4·7·5.webp / C 15항.
- 부모항 조합(14항): 같은 리드 지지부에 복수의 히트리드 모듈 착탈 결합, 제어부가 가열 부재들을 독립 제어.
- 과제: 착탈되는 각 모듈의 가열 부재를 독립 제어하려면, 착탈할 때마다 모듈별로 섞이지 않는 전력 경로가 생겨야 한다.
- E1: 각 모듈이 자기 제2 전력 전달부를 포함하고, 그 제2 전력 전달부는 같은 모듈의 가열 부재와 전기적으로 결합.
- E2: 리드 지지부에 배치된 제1 전력 전달부가 복수의 접속부를 포함.
- E3: 모듈이 결합되면 그 모듈의 제2 전력 전달부가 맞닿는 위치에 접속부가 있다. 서로 다른 모듈은 서로 다른 접속부에 맞닿는다.
- E4: 접속부들은 서로 전기적으로 분리되고, 각 접속부로 가는 전력은 제어부가 접속부별로 조절한다.
- 원리: 결합 동작 자체가 그 모듈 전용 접속부와의 접촉을 만들어 모듈별 독립 전력 경로가 생기고, 제어부는 경로마다 전력 조절.
- 효과: 배선 별도 연결 없이 착탈만으로 모듈별 전력 경로, 14항 독립 제어가 그 경로로 실현.
- 반례 차단: 엉뚱한 자리(E3), 두 모듈 같은 접속부(E3 후단), 공통 버스(E4), 닿기만 하고 미통전(E3 접촉+E1 전기적 결합). 남는 반례 없음.
- 메인 주체: 청구 대상(장치), "…를 더 포함하는" 형식(05 제1.4a 허용). 제어부는 접속부를 꾸미는 관형절 안에만.
- 게이트: SOURCE PASS(E4 분리는 DERIVED) / CAUSAL PASS / CLAIMABILITY PASS / EV PASS / PRIOR_ART UNVERIFIED.
- 권리행사: 분해·통전 시험으로 확인. EV1~EV5 PASS.

## DC-16 (주된 트리, TECHNICAL_SOLUTION_CANDIDATE)
- 근거: B 5·8·3·6.webp, A 화살표·"Pogo pin 방식의 전원 인가"·회의 기술설명, C 3·4·16항.
- 부모항 조합: 14항 + DC-15.
- 과제: DC-15의 "결합되면 맞닿음"을 별도 조작 없이 결합 이동만으로 성립시키는 구조.
- 특징: 결합 방향 = "모듈이 리드 지지부에 결합될 때 이동하는 방향"으로 정의. 플레이트는 모듈의 결합 방향 쪽(앞쪽) 단부. 핀 블록과 복수의 포고 핀이 결합 방향으로 돌출, 포고 핀은 결합되면 접속부에 맞닿음. 복수의 리드 단자가 반대 방향으로 돌출, 그중 적어도 하나가 포고 핀 하나와 같은 모듈의 가열 부재를 전기적으로 연결.
- 원리: 핀 돌출 방향 = 결합 이동 방향 → 삽입 이동이 곧 접촉 이동. 리드 단자가 모듈 내부 경로를 닫음.
- 효과: 착탈 동작 하나로 전력 접속·해제.
- 반례 차단: 플레이트 뒤쪽(앞쪽 단부 한정), 핀 옆향(결합 방향 돌출), 접속부–핀 어긋남(DC-15 E3 + 포고 핀 맞닿음). 남는 반례 없음.
- 메인 주체: 상기 제2 전력 전달부.
- 비고: 포고 핀 압축 축의 접촉압은 청구하지 않음(Q3).
- 게이트: 전부 PASS / PRIOR_ART UNVERIFIED. EV1~EV5 PASS.
