# BLIND SNAPSHOTS dr4 (dbs-DS-hl-ctrl-1519-dr4-c15~c19-01) — blind 보고 원문 요지(판정·표·대안 전부)

공통: BLIND_COMPLETE / BASELINE-c14 / BASELINE / N/A / DS-hl-ctrl-1519 / dd2 / dr4. 오염 없음. 형상 객체표는 16항만 해당(나머지 해당 없음).

## c15 — PARTIAL (발명 유형 PHYSICAL + DATA_CONTROL, HYBRID YES)
- 1회독: 자리마다 접속부(서로 절연된 단자 하나 이상, 그중 하나 이상은 제어부가 자리별 조절한 전력을 받는 전원 단자). 모듈마다 제2 전력 전달부, 끼우면 그 자리 전원 단자에 닿아 연결되고 가열 부재에 전력을 이어 줌.
- 도식: 블록도 수준. 제1 전력 전달부 = 접속부들을 묶는 상자, 지지부에 배치. 제어부→전원 단자 선·제어부 위치는 그리지 않음.
- 중단·미결정: 제1 전력 전달부 배치 면·범위 / 전력 공급원·제어부→단자 경로 / "서로 전기적으로 분리된" 분리 대상(같은 접속부 안 단자끼리 — 가장 자연스러움 / 접속부끼리; 단자 1개면 공허) / 접촉 방향·방식 / 자리·결합 구조 / 제2 전력 전달부 위치·도체.
- 원자 명제 7(배치, 접속부 포함·자리당 하나, 단자·전원 단자, 자리별 조절 전력, 제2 전력 전달부 모듈마다, 결합 시 전원 단자 중 적어도 하나에 맞닿아 접속, 가열 부재–맞닿은 전원 단자 연결).
- 관계표: 위 확정(세부 미기재), 제어부 자리별 조절 "유력", "서로 분리된" 범위 복수해석, 제어부–단자 경로 미기재.
- 가장 자연스러운 모델: 자리마다 단자 묶음, 모듈 접촉부가 결합 시 그 자리 전원 단자에 닿아 가열 부재로 전력 전달, 제어부 자리별 조절.
- 대안: 분리 범위 A/B, 자리 수 ≥ 모듈 수, 제어부 직접 출력/별도 전원 조절, 제1 전력 전달부 범위(배선·기판 포함 여부).
- 비본질 자유도: 단자 수·모양·접촉 방식, 위치, 일체/분리, 모듈당 연결 전원 단자 수.
- 미결정: 경로·공급원, 배치 면, 접촉·결합 방향, 제2 전력 전달부 위치, 비전원 단자 용도, 분리 범위, 자리 수.

## c16 — PARTIAL (PHYSICAL, HYBRID NO)
- 1회독: 모듈 앞끝 판 앞면에 핀 블록·포고 핀, 뒷면에 리드 단자들, 리드 단자 중 하나 이상이 포고 핀 하나와 가열 부재 연결. 도식: 결합 방향 +X, 모듈 +X 끝에 플레이트 → 핀 블록 → 포고 핀, 플레이트 −X 쪽 리드 단자.
- 중단: 플레이트 위치(외면/내부/별체), 관통·지지, 리드 단자 도통 경로, 개수 대응, 미사용 리드 단자 역할.
- 형상 객체: 단면·가상선 없음, 결합 방향은 이동 방향 관찰 기준(실제 면 아님), 4부품 실제 부품 확정, 결합 방향 쪽 단부 유력.
- 원자 명제 7 확정(지지·고정·도통 미기재).
- 대안: 플레이트 별체/하우징 일부, 관통 도통/별도 배선, 리드 단자 모듈 안/바깥, 한 단자에 복수 핀.
- 미결정: 지지·도통 경로, 플레이트 위치, 리드 단자–가열 부재 방식, 탄성 접촉, 개수 대응, 단부 범위·플레이트 면 방향.

## c17 — PARTIAL (PHYSICAL, HYBRID NO)
- 1회독: 전원 핀은 접속부 전원 단자에 닿고 리드 단자 거쳐 가열 부재로, 신호 핀은 전원 핀과 따로 같은 접속부의 비전원 단자에 닿음.
- **막힌 곳: "상기 복수의 포고 핀은, … 결합되면 각각 … 전원 단자 중 어느 하나에 맞닿아 … 접속되며 … 연결되는 하나 이상의 전원 포고 핀"의 수식 범위 — 접속 서술이 "복수의 포고 핀" 전체를 꾸미는지 "전원 포고 핀"만 꾸미는지 문장 구조로 분명하지 않음. 첫 독해는 전원 포고 핀만(근거: 신호 핀이 비전원 단자에 닿는다고 뒤에 따로 적힘).**
- 관계표: 포고 핀 구성 "유력"(목록 구조), 전원 핀–전원 단자 확정, 전원 핀–가열 부재 확정, 신호 핀 분리 확정, **신호 핀–비전원 단자 "확정"("어느 것도 아닌 단자")**, "맞닿아 접속" 서술 귀속 **복수해석**, 신호 행선지 미기재.
- 대안 A: 접속 서술이 포고 핀 전체에 걸림 → 모든 핀이 전원 단자에 닿고 신호 핀 서술과 충돌(자연스러운 독해로 채택 안 함). 대안 B: 신호 핀 행선지(센서/가열 부재 쪽 신호선).
- 미결정: 서술 귀속, 신호 종류·방향·대상, 신호 핀–리드 단자, 핀 배열, 접속부의 비전원 단자 실재(15항 "하나 이상의 단자"만).

## c18 — PARTIAL (PHYSICAL, HYBRID NO)
- 1회독: 리드 단자 중 신호 포고 핀과 이어지고 전원 포고 핀과 분리된 서브 단자가 하나 이상. 뒤쪽 연결 대상 안 나옴. (도식 지시의 "지지부 아래쪽"은 독자 연상.)
- 중단: 서브 단자 연결 대상·기능, 신호 핀과의 개수 대응·직결 여부, 전원 연결 리드 단자·가열 부재와 서브 단자의 분리 여부, 위치·배열.
- 관계표: 포함·연결·분리 확정, 돌출 유력(16 승계), 연결 상대·가열 부재 관계·기능 미기재.
- 대안: 가열 부재 쪽/센서/제어 회로/중계 단자, 1:N·1:1, 이어지지 않는 신호 핀 존재, 가열 부재와 이어지는 서브 단자 허용("전원 포고 핀과 분리"만 요구).
- 미결정: 반대쪽 대상·기능, 개수 대응, 가열 부재 관계, 서브 단자 단수/복수, 전원 연결 리드 단자와 다른 단자인지(유력하나 미명시). 참고: 15항 접속부와 제1 전력 전달부가 나열 항목이면서 포함 관계라 별개로 읽힐 여지(18항 판단엔 무관).

## c19 — PARTIAL (PHYSICAL + DATA_CONTROL(경로만), HYBRID YES)
- 1회독: 모듈 결합 시 서브 단자 → 신호 포고 핀 → 접속부의 비전원 단자 → 제어부 신호선 한 가닥, 모듈마다.
- 중단: 단자–제어부 사이 수단·제어부 위치, "상기 하나 이상의 단자 중 그 신호 포고 핀이 맞닿는 단자"의 접속부 특정은 "맞닿는"에 의존, 서브 단자 모듈당 수.
- 원자 명제 7, 관계표: 연결·시작점·맞닿음·경로 확정, 결합 시점 유력(상시/결합 시 연결 문면상 약함), "차례로 거쳐" 중간 소자 복수해석, 제어부–단자 수단·신호 내용 미기재.
- 대안: 직결/멀티플렉서·릴레이 개재, 상시/결합 시 도통, 공통 제어부/모듈별 제어 회로.
- 미결정: 연결 수단·구간, 신호 종류·방향, 서브 단자 수, 서브 단자–가열 부재, 중간 소자, 연결 성립 시점.
