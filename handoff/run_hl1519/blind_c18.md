- 발명 유형: PRIMARY PHYSICAL; HYBRID YES (제어부·전기 신호·전력 구분, 데이터·단계 한정 없음)

## 목표 종속항의 추가 한정
- 부모 조합: 리드 단자는 플레이트에서 결합 방향 반대로 돌출(16). 포고 핀은 전원/신호로 나뉨(17). 전원 포고 핀은 리드 단자 하나를 거쳐 가열 부재와 연결(17).
- 18 추가: 리드 단자 중 하나인 서브 단자 — 신호 포고 핀 중 적어도 하나와 전기적 연결, 전원 포고 핀(전부)과 전기적 분리.

## 1회독 평이 설명
플레이트 한쪽 면에서 핀 블록과 포고 핀이 접속부 쪽으로 나가고, 반대쪽 면에 리드 단자들이 나온다. 일부 리드 단자는 전원 포고 핀을 가열 부재에 잇는다. 18항은 리드 단자 중 신호 포고 핀에 이어지고 전원 쪽과 떨어진 서브 단자가 있다고 한다. 신호선용 단자가 전원선과 별개로 있다는 정도로 읽힌다. 반대편 끝의 연결 대상은 문언에 없다.

## 1회독 도식화 가능성: PARTIAL
- 플레이트·포고 핀·리드 단자 배치는 도식화됨. 서브 단자의 다른 쪽 끝 연결 대상은 도식화 불가.
- 도식화 지시: ① 모듈 결합 방향 쪽 끝 플레이트 ② 결합 방향 쪽 면에서 핀 블록, 핀 블록에서 포고 핀 여러 개를 결합 방향으로, 접속부에 닿음 ③ 전원/신호 포고 핀 표시 ④ 반대 면에서 리드 단자 여러 개를 결합 방향 반대로 ⑤ 전원 포고 핀 → 리드 단자 하나 → 가열 부재 ⑥ 리드 단자 하나를 서브 단자로, 신호 포고 핀 하나에 연결, 전원 경로와 만나지 않게 ⑦ 서브 단자 반대편 끝은 비워 둠.
- 중단 구절: "서브 단자를 포함하는"(반대편 끝 대상 미기재). 서브 단자와 16항의 핀–가열 부재 연결 리드 단자의 동일성 미정(분리 조건상 별개가 자연스러움). 서브 단자 개수·신호 포고 핀과 1:1 여부 미정.

## 가장 자연스러운 모델
플레이트 뒤쪽 리드 단자 중 전원 경로 단자와 별개로 신호 포고 핀에 이어진 서브 단자가 하나 이상 있고, 전원 경로와 전기적으로 독립이다.

## 대안 모델
- 서브 단자가 가열 부재에 연결/비연결 모두 허용(연결 대상 미기재).
- 제어부 쪽·센서 쪽·어디에도 비연결 모두 허용 — 신호 종류·방향이라는 핵심 협동관계 차이.
- 신호 포고 핀과 1:1 / 여러 핀에 걸침 허용("적어도 하나", "하나 이상").
- 전원 포고 핀과 전기적으로만 분리, 물리 접촉·인접 제한 없음.

## 비본질적 자유도
서브 단자 개수·형태·길이·재질·배치 순서, 단자–포고 핀 접합 방식.

## 문언만으로 결정되지 않는 관계
