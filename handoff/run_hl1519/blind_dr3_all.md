## c15 — PARTIAL (전기 연결도 가능, 기계 스케치 일부)
- 1회독: 자리마다 접속부(단자 묶음), 서로 분리된 단자 중 적어도 하나는 제어부가 자리별 조절한 전력을 받는 전원 단자. 모듈 결합 시 제2 전력 전달부가 자기 자리 접속부 전원 단자에 닿아 통전, 가열 부재와 이어 줌. "자리별 전원 단자 → 제2 전력 전달부 → 가열 부재".
- 미결정: 접촉면 위치·방향, 결합 면(위/아래/옆), 제어부→전원 단자 경로·전원 공급원, 제1·제2 전력 전달부 구체 구조.
- 형상 객체표: 해당 없음.
- 관계표: 모두 확정, 단 접속부 자리당 정확히 하나는 "유력"(뒤 "그 자리의 접속부" 단수), **서로 다른 자리 접속부 사이 전기적 분리는 복수해석**(분리 기재는 한 접속부 안 단자끼리만, 다만 "자리마다 따로 조절"이라 자리별 독립 전력 요구), 비전원 단자 용도·접촉 기하 미기재.
- 대안: 자리 간 공통 전원 모선 + 제어부 자리별 스위칭 모델도 문언상 가능 / 접속부당 전원 단자 하나뿐(분리 공허) / 제2 전력 전달부가 전원 단자 하나·여러 개에 닿음 / 제어부가 전력 출력 vs 별도 전원 조절 / 빈 자리 허용.
- 미결정: 경로·공급원, 결합 면, 제1 전력 전달부 구성, 자리당 접속부 수, 자리 간 분리, 비전원 단자, 닿는 전원 단자 수, 독립 제어와 전력 구조의 인과("그러므로"로 잇지 않음).

## c16 — PARTIAL

- 형상 객체표: 플레이트(결합 방향 기준 확정, 절대 방향·형태 미기재), 핀 블록·포고 핀·리드 단자 돌출 방향 확정.
- 대안: 플레이트 외부 부착/단부 벽 자체, 결합 방향 아래·옆·위, 핀 블록 일체/별체, **가열 부재에 연결된 포고 핀이 전원 단자에 닿는지 비전원 단자에 닿는지 열림**(15항은 제2 전력 전달부–전원 단자 접속을 요구하나 16항 문언만으로는 그 핀과 연결 안 됨), 여러 핀이 같은 단자, 리드 단자 일부만 연결.
- 미결정: 절대 방향, 플레이트–하우징 관계, 지지·관통, 리드 단자–포고 핀 도전 경로, 가열 부재 연결 핀의 전원 단자 접촉 여부, 핀–단자 대응 수.

## c17 — PARTIAL

- 중단·미결정: 신호 종류·방향·모듈 쪽 끝 / **"상기 하나 이상의 단자 중 상기 전원 단자와 전기적으로 분리된 단자": "상기 전원 단자"가 (a) 전원 포고 핀이 닿는 그 전원 단자 (b) 접속부 전원 단자 전체 두 갈래 → 신호 핀이 닿는 단자가 비전원 단자인지 다른 전원 단자일 수도 있는지 갈림** / 핀 수·배열.

- 대안: **신호 핀이 다른 전원 단자에 닿는 모델 — 접속부 단자들은 이미 서로 분리돼 있어 "전원 단자와 분리된 단자"가 비전원 단자만 뜻한다고 문언만으로 확정되지 않음** / 신호 핀 모듈 쪽 종단 열림(가열 부재 직결은 분리 조건과 충돌).
- 미결정: 신호, 신호 단자–제어부 관계, 신호 핀 종단, 비전원 한정 여부, 핀 수·배치.
